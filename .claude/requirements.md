# Goal

To Create a platform to learn react and typescript for a beginner who understands javascripts and programming basics.

## Scope

This should be a 30 day plan
The whole session needs to setup for 1 hour per day
It should start with a introduction to javascript, react and typescript
It should show how to install react
Platform should teach the concepts, thinking pattern, walkthrough with example
Platfrom should give user to practice the concept/topic
Platform should review all practices and give feedback and give the correct answer
Platform should give a challenge to test the paticular concept or topic
Each concept, topic should have a link to a formal website reference to read and understand if required
App should use the full screen space for this, left pane can be utilised for explanations and right pane for practices.
This practice enviornment can work like a codepen, a javascript runnable enviornment to run and test results and point if there are mistakes
Progress should be recorded
Dark mode / light mode needs to be implemented
This training needs to be cover React, TypeScript from basics to advance level. So Better to have a CRM tool in mind and break it into peaces so along the way the user will know how to develop a CRM using react
This should cover advance topic like connect to APIs and manage responses and manage caching, offline data, local storage and more.


## Techstack 
Use a simple javascript, html, css approach to build this platform. You can use any framework if required. No need of any database, store the data in a file, json or localstorage.

## Hosting
This will be hosted in github and deployed in vercel
